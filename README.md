# ARRE ASET - Sistem Manajemen Inventaris Barang

Sistem manajemen inventaris barang berbasis web yang dibangun menggunakan **Laravel**.  
Aplikasi ini digunakan untuk mencatat, mengelola, dan memantau kondisi aset/barang inventaris.

## Fitur

- Autentikasi (Login & Register)
- Dashboard ringkasan aset
- CRUD Data Barang (Tambah, Edit, Hapus)
- Informasi Kondisi Barang (Baik, Perbaikan, Rusak)
- Tampilan modern dan responsif

## Teknologi yang Digunakan

- Laravel 11 / 12
- Laravel Breeze (Authentication)
- MySQL
- Tailwind CSS
- Blade Template
